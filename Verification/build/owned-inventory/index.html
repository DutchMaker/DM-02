Owned inventory changes the preferred parts

Eleven reported stock types are recorded; the repeated W27C512 mention is counted once. Numeric quantities remain blank. The workbook fills only its existing ownership/notes inputs; selected FD1 parts and design counts remain the original reference.

This is a suitability review and inventory update. An owned-parts circuit has not yet been simulated or promoted.

Prioritize an owned-parts variant using 27C322 for the ALU, UM61512AK-15 for SRAM, W27C512-45Z for program ROM, and assess 27C1024 for the complete control word. Reassess the large mux/buffer fabric against available HCT245, HCT574 and HCT191 stock.

Owned partRecommended use and required changes
27C322Preferred ALU-ROM route to revisit now that stock is owned

The 2M x16 organization matches the existing complete ALU image. AL1 already provides a legacy-ROM circuit/model route. Replacing AL2's eight-flash array could remove its bank mux/address-buffer overhead. Exact speed, package and programmer support must be checked, and the chosen AL1 variant reconnected and verified in FD1.

27C1024Strong single-chip control-ROM candidate

The documented M27C1024 organization is 64K x16, matching the 65,536-word control store. One device could replace the two byte-wide control ROMs after a controller pinout/footprint change. Manufacturer and speed suffix are still unknown. It is much smaller than a 27C322 and is not a one-chip ALU-ROM substitute.

UM61512AK-15Yes: suitable SRAM capacity and a promising faster owned candidate

64K x8, 15 ns; the current AS6C1008 design grounds A16, so its extra capacity is unused. UMC specifies the K part as skinny DIP-32, unlike the current wide DIP-32 footprint. UMC pins 1 and 2 are NC; current AS6C1008 pin 2 is grounded A16. Use an exact symbol/footprint and revised timing/load model. Recommended DC supply is 4.75..5.25 V; read load 30 pF, high-Z timing test 5 pF, operating current up to 160 mA. Owned SRAM does not remove the separate turnaround qualification gap.

W27C512-45ZYes: strong program-ROM candidate; also usable as a control-ROM byte lane

64K x8, 45 ns, lead-free 28-pin 600-mil DIP. Read-mode pin assignment matches the current 27C512-style ROM connections. One can cover the program-ROM role; two could cover the control ROM if that architecture is retained. The 45 ns rating uses 30 pF, read supply 4.75..5.25 V, and address-change output hold is 0 ns rather than the current AT27C512R model's 7 ns. Electrical erase/programming needs the correct programmer algorithm and elevated voltages (14 V erase / 12 V program); it is not a 5 V in-circuit byte-write EEPROM.

74HCT377Reuse candidate for the retained operand-register functions

The candidate already uses two HCT377 packages, currently selected as CD74HCT377M96 SOIC. Owned DIP variants can avoid that package procurement choice once their full markings and timing are checked. The earlier nominal DIP screen covered CD74HCT377E; it did not qualify every vendor's HCT377.

74HCT245Design around the plentiful stock where the electrical role permits

A 245 can serve as an eight-bit unidirectional non-inverting buffer with DIR fixed, but has a different pin map and one common OE instead of the 244's two group enables. HCT cannot inherit AHCT propagation/drive limits, especially on clock and high-fanout paths. A 245 does not directly replace a 157 mux; using tri-state drivers as selection requires explicit non-overlap control and timing verification.

244 / 157Scarce stock; exact logic family still unknown

User reported fewer 244 and 157 devices than 74HCT245. Do not infer AHCT or HCT from these abbreviated numbers. The current 68 AHCT244 / 84 AHCT157 counts belong to the expanded FD1 architecture and should not be treated as an owned-parts shopping list.

74HCT574Reuse in existing 574 roles; reconsider simpler register-bank architecture

Five HCT574s are already in the current candidate. Their use in a redesigned general-register bank could reduce AC175/mux overhead, but a 574 lacks a clock-enable input: its OE only controls outputs. Register writes need a qualified load/clock strategy. Confirm manufacturer/package and counts.

74HCT191Useful stack/address-counter option requiring architectural work

This is a 4-bit up/down counter, relevant to the original stack/address roles. Current SP1/MA1 use adders, staging registers and muxes. Reusing 191s requires reviewing cascade, parallel-load, output timing and reset behaviour; it is not a pin-for-pin substitution for that architecture.

74HCT161Reuse candidate for PC and sequencer counters

The current candidate already uses five HCT161s (four PC, one sequencer), selected as SOIC because of procurement status. Owned DIP stock makes that availability argument irrelevant for this prototype. Exact manufacturer/package timing still needs matching.

Needed to choose exact variants

Full markings or clear photos (especially 27C322/27C1024 speed suffixes), approximate quantities and the programmer model/adapters.
