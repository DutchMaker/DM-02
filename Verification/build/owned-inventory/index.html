The workbook now opens with the DIP logic candidate: all 91 SOIC logic positions have staged DIP replacements, including 48 CD74ACT175E flip-flops. The earlier component list is labelled “Reference FD1 BOM”.

Fifteen owned types and one explicitly unowned type are recorded. One 74HCT157 and zero CD74ACT175E are confirmed; other numeric quantities remain blank. Source 48 ACT175s for the current DL1 candidate. The latest SN74HC377N marking replaces the earlier HCT377 stock report. Exact markings and ownership appear in the Reported stock tab and in the active DIP tabs.

Through-hole construction required. All owned logic and memory ICs are DIP; no SOIC. MCP100-450D is a through-hole TO-92 supervisor. DL1 has zero SOIC logic packages; eight PLCC flash ICs still await the owned-M27C322 conversion. Integrated timing and physical qualification remain pending.

This is a suitability review and inventory update. An owned-parts circuit has not yet been simulated or promoted.

Develop a through-hole variant using owned M27C322-100F1 for the ALU, M27C1024-10F1 for the control word, UM61512AK-15 for SRAM and W27C512-45Z for program ROM. All logic and memory must use DIP packages; SOIC is excluded. Reassess the mux/buffer fabric against available HCT245, HCT574 and HCT191 stock and one HCT157; more muxes can be obtained if verification shows a need.

Reported partRecommended use and required changes
M27C322-100F1Exact match to the existing AL1 ROM timing model

ST 2M x16, 100 ns, windowed FDIP42W; multiple devices owned. Verification/alu-parts.json already models this exact part with 5 ns output hold and a 100 pF timing load. Replacing AL2's eight-flash array could remove its bank mux/address-buffer overhead. The AL1 route still needs a DIP-only supporting circuit and integrated FD1 verification. Programmer support remains to be checked.

M27C1024-10F1Preferred single-chip control-ROM candidate, 100 ns

ST 64K x16, 100 ns (-10), windowed FDIP40W (F), commercial temperature grade (1). Its organization matches the 65,536-word control store. One device could replace the two byte-wide control ROMs after controller pinout, footprint and timing-model changes. Verify the 100 ns access, enable/hold limits and loading in the integrated controller. Programmer support remains to be checked.

UM61512AK-15Yes: suitable SRAM capacity and a promising faster owned candidate

64K x8, 15 ns; the current AS6C1008 design grounds A16, so its extra capacity is unused. UMC specifies the K part as skinny DIP-32, unlike the current wide DIP-32 footprint. UMC pins 1 and 2 are NC; current AS6C1008 pin 2 is grounded A16. Use an exact symbol/footprint and revised timing/load model. Recommended DC supply is 4.75..5.25 V; read load 30 pF, high-Z timing test 5 pF, operating current up to 160 mA. Owned SRAM does not remove the separate turnaround qualification gap.

W27C512-45ZYes: strong program-ROM candidate; also usable as a control-ROM byte lane

64K x8, 45 ns, lead-free 28-pin 600-mil DIP. Read-mode pin assignment matches the current 27C512-style ROM connections. One can cover the program-ROM role; two could cover the control ROM if that architecture is retained. The 45 ns rating uses 30 pF, read supply 4.75..5.25 V, and address-change output hold is 0 ns rather than the current AT27C512R model's 7 ns. Electrical erase/programming needs the correct programmer algorithm and elevated voltages (14 V erase / 12 V program); it is not a 5 V in-circuit byte-write EEPROM.

SN74HC377NPlausible reuse in two positions; HC input and timing review required

Latest marking corrects the earlier HCT377 report; separate HCT377 ownership is not inferred. AL1 U6 data comes from DF1 AHCT244 outputs; U7 function data comes from CW1 HCT574 outputs. Both clocks use AHCT244 and enables use AHCT00. At the shared 4.5 V datasheet point these drivers exceed HC377 VIH=3.15 V. Full supply/load margins and timing remain pending. TI specifies 40 ns clock-to-Q, 25 ns data/enable setup, 5 ns hold and 25 ns clock pulse at 4.5 V, -40..85 C, CL=50 pF. Keep selected CD74HCT377E until integration is checked.

74HCT245Design around the plentiful stock where the electrical role permits

A 245 can serve as an eight-bit unidirectional non-inverting buffer with DIR fixed, but has a different pin map and one common OE instead of the 244's two group enables. HCT cannot inherit AHCT propagation/drive limits, especially on clock and high-fanout paths. A 245 does not directly replace a 157 mux; using tri-state drivers as selection requires explicit non-overlap control and timing verification.

244Scarcer DIP stock; logic family still unknown

User reported fewer 244 devices than 74HCT245. Manufacturer, family and count remain unknown. The current 68 AHCT244 count belongs to the reference FD1 architecture; assess HCT245 buffer alternatives per electrical role.

74HCT157One DIP mux owned; more obtainable if needed

Family and quantity are confirmed. Exact manufacturer/suffix remain unknown. HCT157 timing must be modelled separately from AHCT157. The reference 84 AHCT157 count is not a purchasing requirement for the owned-DIP variant; determine the requirement after redesign and verification.

74HCT574Reuse in existing 574 roles; redesign needed to replace 175 registers

Five HCT574s are already in the reference candidate. A 574 lacks asynchronous clear, complementary outputs and clock enable; OE only controls outputs. All 48 reference AC175 positions use reset and three use complementary outputs. Reusing 574s for those registers therefore requires new reset/write behaviour and verification. DL1 uses pin-compatible CD74ACT175E DIP devices for that conversion. DIP ownership is confirmed; manufacturer/suffix and counts remain unknown.

74HCT191Useful stack/address-counter option requiring architectural work

This is a 4-bit up/down counter, relevant to the original stack/address roles. Current SP1/MA1 use adders, staging registers and muxes. Reusing 191s requires reviewing cascade, parallel-load, output timing and reset behaviour; it is not a pin-for-pin substitution for that architecture.

CD74HCT161EExact selected DIP counter is owned

Matches the DL1 selection for five PC/sequencer counters. Quantity remains unknown; ownership does not establish that all five are available or physically tested.

74HCT154NOwned DIP decoder option for four positions

Historical Philips documentation lists 74HCT154N as DIP24/SOT101-1, the wide 600-mil package. The owned manufacturer's logo and count remain unknown. This provides an owned decoder route; exact vendor pin/timing matching is required before changing DL1's CD74HCT154E identity.

SN74HCT00NOwned DIP NAND alternative; slower than selected AHCT

Same NAND function and DIP pin assignment. TI gives 25 ns maximum propagation delay at 4.5 V, 50 pF, -40..85 C versus the reference AHCT model's 9 ns. Clock/enable/reset path delay, pulse widths and setup/hold must be recomputed before substitution. Count unknown.

SN74HCT08NOwned DIP AND alternative; slower than selected AHCT

Same AND function and DIP pin assignment. TI gives 30 ns maximum propagation delay at 4.5 V, 50 pF, -40..85 C versus the reference AHCT model's 9 ns. Clock gating, pulse widths and setup/hold need renewed checks; a slower oscillator alone does not qualify these paths. Count unknown.

CD74ACT175EZero owned; source 48 for the current DL1 candidate

User explicitly owns none. TI lists the DIP-16 part; availability at a supplier remains unconfirmed. The current candidate uses 48; possible register consolidation has not been implemented and does not reduce this candidate quantity.

MCP100-450DOwned through-hole reset supervisor; existing supply-coverage gap remains

This exact TO-92 part already appears in the reset design. Existing DS11187F evidence gives a 4.25/4.375/4.50 V min/typ/max trip range and a 150/350/700 ms release delay. Release timing starts at threshold crossing, which may precede reaching the machine's 4.75 V valid-supply floor. Brownout assertion has only a typical delay in the cited table. Ownership resolves sourcing, while slow-ramp/startup, brownout and receiver recovery/removal still need qualification.
