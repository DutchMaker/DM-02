                                                                                                                UM61512A Series


                                                                            64K X 8 BIT HIGH SPEED CMOS SRAM


Features

   Single +5V power supply                                                                Common I/O using three-state output
   Access times: 15/20/25ns (max.)                                                        Output enable and two chip enable inputs for easy
   Current: Operating: 160mA (max.)                                                       application
               Standby:    10mA (max.)                                                    Data retention voltage: 3V (min.)
   Full static operation, no clock or refreshing required                                 Available in 32-pin SKINNY DIP, TSOP, SOP, SOJ
   All inputs and outputs are directly TTL compatible                                     and both 300/400 mil packages


General Description

The UM61512A is a low operating current 524,288-bit                                   Two chip enable inputs are provided for POWER-DOWN
static random access memory organized as 65,536                                       and device enable and an output enable input is included
words by 8 bits and operates on a single 5V power                                     for easy interfacing.
supply. It is built using UMC's high performance CMOS                                 Data retention is guaranteed at a power supply voltage
process.                                                                              as low as 3V.
Inputs and three-state outputs are TTL compatible and
allow for direct interfacing with common system bus
structures.
